# AI Builder Starter Kit

My Claude Code + Codex setup, with curated skills and templates for building products and running your workflows.

## What’s inside

- **Skills** — evaluated for practical use across models.
- **Development** — build, test, debug, and ship.
- **Research** — find sources and turn findings into decisions.
- **Second brain** — organize knowledge and project context.
- **Business** — support planning, content, and daily operations.
- **Automation** — streamline repeatable tasks.

## Start here

Clone this repo, pick a template, and follow its setup instructions. Install the skills you need as you go.

## Built live. Maintained together.

This repo started with a community live build. We install, test, and improve the setup together as the tools evolve.

Found a bug, have a question, or want to suggest an improvement? Open an issue. We’ll use the Issues page to choose what to work on together during every live call.
